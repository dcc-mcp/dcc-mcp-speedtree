run describes this licensed installation; it is not a guarantee for every
edition, subscription, or source asset. Each permitted export format below
was generated by the official CLI and checked for a recognizable file header,
nonempty mesh, file inventory hashes, and explicit material sidecar references
where present. Vendor assets and raw local logs are not distributed here.

Houdini/Unity handoffs use the same bundle contract; destination validation is
owned by their adapters and is not claimed by this baseline. USD, Alembic, and
other importer availability must be discovered in the particular target.
GLTF/GLB, legacy SRT, STE, and XML are not export tool options in this release;
file discovery support does not imply verified export support.
